โปรเจคนี้มี 3 โฟลเดอร์
NocoBaseRestaurant
- BocoBaseFrontEnd
- NocoBaseBackEnd
- NocoBaseRealTimeServer

โดยตัวที่น่าจะต้องนำไปรันบน cloud คือ 
- NocoBaseBackEnd
- NocoBaseRealTimeServer

ซึ่ง NocoBaseBackEnd ผมใช้ docker มี container 2 ตัว คือ app กับ posgresql
ส่วน NocoBaseRealTimeServer ใช้ socket.io ครับ

ส่วน frontend ผมจะนำไปรันบน share เพราะใช้แค่ html jquery ทั่วไป

รบกวนแนะนำวิธีการ deploy เฉพาะ backend และ realtime server ครับ
